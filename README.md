# Workspace MCP Server

Локальный MCP-сервер для работы с файлами текущего workspace. Реализация разделена на три слоя:

- `src/server.js` — MCP-протокол и обработчики запросов.
- `src/validation.js` — проверка входных аргументов.
- `src/workspace-service.js` — файловые операции, ограниченные корнем workspace.

## Запуск

```powershell
npm install
npm start
```

По умолчанию корень workspace — текущая папка запуска. Его можно переопределить переменной `MCP_WORKSPACE_ROOT`.

## Инструменты

- `list_directory` — список элементов каталога.
- `read_file` — чтение файла или диапазона строк.
- `write_file` — создание, перезапись или добавление текста.
- `search_files` — поиск по именам и содержимому.
- `get_workspace_info` — краткая информация о проекте.

Пути должны быть относительными, родительские сегменты (`..`) и символические ссылки запрещены. Чтение и MCP-ресурсы ограничены файлами до 1 МБ; запись ограничена 1 МБ, чтение — 10 000 строк за запрос.
